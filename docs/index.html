gpx2server

Turn a GPX hike into a themed map (PNG), an animation (GIF, MP4), or a laser-ready SVG for engraving, rendered by GitHub Actions. The GPX goes through a secret gist that is deleted once the run is over; nothing is committed.

GitHub access

Public-repo runs use unlimited free Actions minutes. Enter a token to check your account.
